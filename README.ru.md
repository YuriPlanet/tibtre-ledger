# TIBTRE — система оценки и учёта вкладов в VERA20k

**TIBTRE** — система оценки и учёта вкладов в [VERA20k](https://github.com/YuriPlanet/vera20k). Она определяет, как оцениваются и учитываются принятые вклады участников и как они влияют на решения по проекту.

В этом репозитории хранятся [правила](RULES.md), [журнал вкладов](LEDGER.csv), в который записи только добавляются, автоматически сформированные [балансы](BALANCES.md) и инструменты для независимой проверки записей.

VERA20k и этот репозиторий размещены в [YuriPlanet](https://github.com/YuriPlanet), нашей организации на GitHub.

## Зачем нужен TIBTRE

Проект VERA20k создают его участники, и основная идея в том, что он должен им *принадлежать*. TIBTRE воплощает эту идею в жизнь заранее, ещё до того, как это станет важно:

- **Справедливость наперёд.** Если для VERA20k когда-нибудь будет создано юридическое лицо или у проекта появится доход для распределения, на трудный вопрос — *кто это построил и какой вклад внёс?* — уже будет ответ: публичный и проверяемый, с первого дня. Этот журнал — заявленная основа для любого такого распределения. Это лишь добросовестное намерение, а не юридическое обязательство.
- **Реальный голос уже сегодня.** Решения о направлении развития VERA20k взвешиваются по tibtre — с ограничением, чтобы ни один держатель никогда не мог доминировать ([`voteweight.py`](voteweight.py)).
- **Постоянная запись.** Вклады оцениваются по публичным правилам ([критерии оценки](docs/grading-rubric.md)), записываются навсегда и могут быть проверены кем угодно.

Один tibtre ≈ один час качественной работы над тем, что действительно нужно VERA20k, — учитываются и качество, и ценность, и то и другое оценивается по публичным правилам. Подавать заявку не нужно: вноси вклад, получай оценку, попадай в журнал.

## Карта репозитория

| Файл / папка | Что это |
|---|---|
| `RULES.md` | Правила: что такое tibtre, как его заработать и сколько он стоит |
| `LEDGER.csv` | Журнал начислений, в который записи только добавляются, с ID участника в каждой строке — единственный источник истины |
| `CONTRIBUTORS.csv` | ID → публичное отображаемое имя (необязательно, можно менять; пусто = псевдонимно, только ID) |
| `BALANCES.md` | Сгенерированная таблица балансов — после правки журнала запусти `python tally.py` |
| `tally.py` | Заново генерирует `BALANCES.md` из `LEDGER.csv` |
| `voteweight.py` | Считает засчитываемые веса голосов с ограничением 25 % на человека (`--demo` — примеры) |
| `identity.py` | Создаёт и проверяет обязательства (commitments) идентичности |
| `docs/granting-guide.md` | Пошаговое руководство для утверждающих, которые записывают начисление |
| `assets/` | Архив принятых работ сообщества и других материалов, не являющихся кодом |

## Соглашения

- В журнал записи **только добавляются**: прошлые строки никогда не изменяются и не удаляются. Исправления оформляются новой строкой (отрицательные суммы допустимы — с примечанием о причине).
- Журнал содержит **только ID участников** (случайные, например `T-83DE`) и никогда — имена. Отображаемые имена хранятся в `CONTRIBUTORS.csv`; их можно в любой момент изменить или очистить, не затрагивая историю.
- Каждое изменение фиксируется в git — история коммитов *и есть* журнал аудита.
