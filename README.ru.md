# TIBTRE — система оценки и учёта вкладов в VERA20k

**TIBTRE** — система учёта вкладов в [VERA20k](https://github.com/YuriPlanet/vera20k). Те, кто помогает создавать VERA20k, получают баллы, которые называются **tibtre**, а этот репозиторий — их публичный учёт. VERA20k и этот репозиторий размещены в [YuriPlanet](https://github.com/YuriPlanet), нашей организации на GitHub.

## Как это работает

1. **Вы вносите вклад.** Засчитываются код, исследования, графика, карты, тестирование, переводы и работа с сообществом. Аккаунт на GitHub не нужен: свою работу можно выложить в Discord.
2. **Вашу работу оценивают.** Когда работа принята, ИИ и мейнтейнер вместе оценивают её по [публичным правилам оценки](docs/grading-rubric.md). Один tibtre — это примерно час хорошей работы над тем, что нужно VERA20k. Правила одни для всех, включая мейнтейнеров.
3. **Это записывается.** Каждое начисление — строка в публичном [журнале](LEDGER.csv) под вашим ID участника (например, `T-83DE`), а не под вашим именем. Строки никогда не изменяются и не удаляются. Ошибку исправляют новой строкой.
4. **Проверить может любой.** Балансы всех участников — в [BALANCES.md](BALANCES.md).

## Зачем нужен tibtre

- **Голос в проекте.** В голосованиях о направлении развития VERA20k больше tibtre — больше голос, но вес одного человека никогда не превышает 25 % голосования.
- **Справедливое распределение.** Если для VERA20k когда-нибудь будет создано юридическое лицо или у проекта появится доход для распределения, этот журнал — заявленная основа для любого такого распределения. Это лишь добросовестное намерение, а не юридическое обязательство.

Все правила — в [RULES.md](RULES.md) (на английском).
