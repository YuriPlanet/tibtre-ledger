# tibtre-ledger

ที่นี่คือบ้านของ **tibtre** สกุลเงินแห่งการมีส่วนร่วมของสหกรณ์ YuriPlanet รีโพสิทอรีนี้เก็บนโยบาย สมุดบัญชีที่บันทึกเพิ่มได้อย่างเดียว ยอดคงเหลือที่สร้างขึ้นอัตโนมัติ และเครื่องมือที่ทำให้ทุกตัวเลขในระบบตรวจสอบได้อย่างอิสระ

## ทำไมต้องมี tibtre

Yrvera สร้างขึ้นโดยผู้มีส่วนร่วม และแนวคิดตั้งต้นคือโปรเจกต์นี้ควร*เป็นของ*พวกเขา tibtre คือสิ่งที่ทำให้แนวคิดนี้เป็นรูปธรรมตั้งแต่ก่อนที่มันจะสำคัญ:

- **ความเป็นธรรมล่วงหน้า** หากวันหนึ่ง Yrvera จัดตั้งนิติบุคคลหรือมีรายได้ที่ต้องแบ่งปัน คำถามยาก ๆ อย่าง *ใครสร้างสิ่งนี้ และสร้างไปมากแค่ไหน* ก็มีคำตอบอยู่แล้ว อย่างเปิดเผยและตรวจสอบได้ตั้งแต่วันแรก สมุดบัญชีนี้คือหลักที่ประกาศไว้สำหรับการแบ่งสรรเช่นนั้น
- **มีสิทธิ์มีเสียงจริงตั้งแต่วันนี้** การตัดสินใจเรื่องทิศทางของ Yrvera ถ่วงน้ำหนักตาม tibtre โดยมีเพดานจำกัด เพื่อไม่ให้ผู้ถือรายใดรายหนึ่งครอบงำได้เลย ([`voteweight.py`](voteweight.py))
- **บันทึกถาวร** การมีส่วนร่วมได้รับการประเมินมูลค่าตามกฎที่เปิดเผย ([เกณฑ์การประเมิน](docs/grading-rubric.md)) ถูกบันทึกไว้ตลอดไป และใครก็ตรวจสอบได้ รวมถึงตัวผู้มีส่วนร่วมเอง โดยไม่ต้องไว้ใจใคร ([`identity.py`](identity.py))

1 tibtre ≈ งานคุณภาพสูงหนึ่งชั่วโมงกับสิ่งที่ Yrvera ต้องการจริง ๆ ทั้งคุณภาพและคุณค่าล้วนนับรวม และทั้งสองอย่างกำหนดราคาตามกฎที่เปิดเผย ไม่ต้องยื่นขออะไร แค่มีส่วนร่วม ได้รับการประเมิน แล้วถูกบันทึก

## แผนผังรีโพสิทอรี

| ไฟล์ / โฟลเดอร์ | คืออะไร |
|---|---|
| `RULES.md` | นโยบาย: tibtre คืออะไร ได้มาอย่างไร และมีค่าแค่ไหน |
| `LEDGER.csv` | สมุดบัญชีการมอบ tibtre ที่บันทึกเพิ่มได้อย่างเดียว อ้างอิงด้วยรหัสผู้มีส่วนร่วม เป็นแหล่งข้อมูลที่ถูกต้องเพียงแหล่งเดียว |
| `CONTRIBUTORS.csv` | รหัส → ชื่อที่แสดงต่อสาธารณะ (ไม่บังคับ เปลี่ยนได้ เว้นว่าง = ไม่เปิดเผยชื่อ แสดงเฉพาะรหัส) |
| `BALANCES.md` | ตารางยอดคงเหลือที่สร้างอัตโนมัติ รัน `python tally.py` หลังแก้ไขสมุดบัญชี |
| `tally.py` | สร้าง `BALANCES.md` ใหม่จาก `LEDGER.csv` |
| `voteweight.py` | คำนวณน้ำหนักเสียงโหวตที่นับจริงภายใต้เพดาน 25% ต่อคน (ใช้ `--demo` เพื่อดูตัวอย่าง) |
| `identity.py` | สร้างและตรวจสอบข้อผูกมัดตัวตน (commitment) ที่เปิดเผยต่อสาธารณะ พิสูจน์ได้ว่ารหัสเป็นของคุณโดยไม่ต้องไว้ใจใคร |
| `docs/granting-guide.md` | คู่มือทีละขั้นตอนสำหรับผู้อนุมัติที่บันทึกการมอบ tibtre |
| `assets/` | คลังผลงานศิลปะจากชุมชนที่ได้รับการยอมรับ และชิ้นงานอื่นที่ไม่ใช่โค้ด |

## ข้อตกลง

- สมุดบัญชี**บันทึกเพิ่มได้อย่างเดียว** ห้ามแก้ไขหรือลบแถวเดิมเด็ดขาด การแก้ไขข้อผิดพลาดให้เพิ่มแถวใหม่ (ใช้จำนวนติดลบได้ พร้อมหมายเหตุอธิบายเหตุผล)
- สมุดบัญชีมี**เฉพาะรหัสผู้มีส่วนร่วม** (สุ่มขึ้น เช่น `T-83DE`) ไม่มีชื่อคนเลย ชื่อที่แสดงเก็บไว้ใน `CONTRIBUTORS.csv` และแก้ไขหรือลบออกได้ทุกเมื่อโดยไม่กระทบประวัติ
- การจับคู่รหัสกับตัวบุคคลจริงเก็บไว้ใน**โฟลเดอร์ส่วนตัวที่แยกต่างหาก** (`../vera20k-tibtre-private/`) ซึ่งต้องไม่เผยแพร่เด็ดขาด
- ทุกการเปลี่ยนแปลงจะถูกคอมมิตลง git ประวัติคอมมิต*คือ*หลักฐานสำหรับการตรวจสอบ
- เอกสารเกี่ยวกับ tibtre ทั้งหมดในอนาคตให้ใส่ไว้ใน `docs/`
- ผลงานศิลปะที่ได้รับการยอมรับให้ใส่ไว้ใน `assets/` โดยตั้งชื่อเป็น `YYYY-MM-DD_T-XXXX_short-title.ext` (ใช้รหัส ห้ามใช้ชื่อ เพราะชื่อไฟล์เป็นสาธารณะและถาวร)
