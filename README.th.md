# TIBTRE — ระบบการมีส่วนร่วมของ VERA20k

**TIBTRE** คือระบบการมีส่วนร่วมของ [VERA20k](https://github.com/YuriPlanet/vera20k) ผู้ที่ช่วยสร้าง VERA20k จะได้รับแต้มที่เรียกว่า **tibtre** และรีโพสิทอรีนี้คือบันทึกสาธารณะของแต้มเหล่านั้น VERA20k และรีโพสิทอรีนี้อยู่ภายใต้ [YuriPlanet](https://github.com/YuriPlanet) ซึ่งเป็นองค์กรของเราบน GitHub

## ทำงานอย่างไร

1. **คุณมีส่วนร่วม** โค้ด งานวิจัย งานศิลป์ แผนที่ การทดสอบเล่น งานแปล และงานชุมชน ล้วนนับรวม ไม่จำเป็นต้องมีบัญชี GitHub คุณโพสต์ผลงานใน [Discord](https://discord.gg/kmjRUn5m5F) หรือกลุ่ม QQ (1097193563) ได้
2. **ผลงานของคุณได้รับการประเมิน** คุณไม่ต้องขอ ผู้ดูแลโครงการน่าจะเห็นผลงานของคุณเอง และคุณจะได้รับ tibtre โดยอัตโนมัติ ผลงานที่ได้รับการยอมรับจะได้รับการประเมินร่วมกันโดย AI และผู้ดูแลโครงการ ตาม[กฎการให้คะแนนที่เปิดเผย](docs/grading-rubric.md) 1 tibtre เท่ากับงานดี ๆ ประมาณหนึ่งชั่วโมงกับสิ่งที่ VERA20k ต้องการ ทุกคนใช้กฎเดียวกัน รวมถึงผู้ดูแลโครงการด้วย
3. **มีการบันทึกไว้** การให้ tibtre แต่ละครั้งเป็นหนึ่งแถวใน[สมุดบัญชี](LEDGER.csv)สาธารณะ โดยใช้รหัสผู้มีส่วนร่วมของคุณ (เช่น `T-83DE`) ไม่ใช่ชื่อของคุณ แถวเดิมจะไม่ถูกแก้ไขหรือลบเลย ถ้ามีข้อผิดพลาดจะแก้ด้วยแถวใหม่
4. **ใครก็ตรวจสอบได้** ยอดรวมของทุกคนอยู่ใน [BALANCES.md](BALANCES.md)

## tibtre มีไว้ทำอะไร

- **มีเสียงในโครงการ** ในการโหวตเรื่องทิศทางของ VERA20k ยิ่งมี tibtre มากก็ยิ่งมีเสียงมาก แต่ไม่มีใครคนเดียวที่มีน้ำหนักเกิน 25% ของการโหวต
- **การแบ่งปันอย่างเป็นธรรม** หากวันหนึ่ง VERA20k จัดตั้งนิติบุคคลหรือมีรายได้ที่ต้องแบ่งปัน สมุดบัญชีนี้คือหลักที่ประกาศไว้สำหรับการแบ่งสรรเช่นนั้น นี่เป็นเพียงเจตนาโดยสุจริตเท่านั้น ไม่ใช่ข้อผูกพันทางกฎหมาย

กฎทั้งหมดอยู่ใน [RULES.md](RULES.md) (ภาษาอังกฤษ)
